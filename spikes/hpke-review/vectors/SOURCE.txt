The CFRG HPKE test-vector file referenced by RFC 9180, subset for the AD-18 suite. RFC 9180
Appendix A prints no vector for DHKEM(X25519) with AES-256-GCM; this file carries one.

          The hpke 0.13.0 package ships the same bytes as test-vectors-5f503c5.json.

Subset:   rfc9180-base-x25519-sha256-aes256gcm.json, the entries with mode 0 (base),
          kem_id 0x0020 (DHKEM(X25519, HKDF-SHA256)), kdf_id 0x0001 (HKDF-SHA256) and
          aead_id 0x0002 (AES-256-GCM): one vector, its encryptions and exports, values
          unchanged, re-indented. Its SHA-256 is in SHA256SUMS.

Checks:   run.sh `vectors-subset-sha256` checks the subset against SHA256SUMS;
          run.sh `upstream-vectors-sha256` checks the copy in the hpke package against the
          upstream SHA-256 above; the test
          `subset_is_exactly_the_suite_entries_of_the_upstream_file` filters that copy and
          compares the result with the subset, value for value.
