# Story 4.8: Backup key pair from the backup secret

As an instance admin,
I want a backup secret generated by the Core from which the backup key pair is derived,
So that backups run unattended to a public key while only the holder of the secret can restore.

**Acceptance Criteria:**

**AC1 (FR-53, D106)**
**Given** the Core generating a backup secret
**When** it is created
**Then** it has at least 128 random bits, is never chosen by a person, and is rendered in a display format meant to be written down (grouped characters with a checksum)
**And** it is never stored on the host

**AC2 (AD-31, D85)**
**Given** a backup secret
**When** the backup key pair is derived
**Then** Argon2id stretches the secret and the HPKE `DeriveKeyPair` function of RFC 9180 produces the X25519 key pair
**And** the same secret always yields the same key pair (test vectors kept in the repository)

**AC3 (AD-31, D85)**
**Given** a derived key pair
**When** it is stored
**Then** only the public key is written to Core metadata, and the private key exists in memory only during a restore and is zeroized afterwards

**AC4 (FR-53, D106)**
**Given** a key or a wrapper to put in a backup
**When** the Core seals it to the backup public key
**Then** it uses an HPKE public-key wrapper of `doc/key-management.md` section 9, and only the private key re-derived from the backup secret opens it (test with a wrong secret)

**AC5 (D128, D120)**
**Given** the backup secret
**When** it is stretched and the key pair derived
**Then** the Argon2id stretch goes through the one limiter of Story 4.4 AC6, which D128 names the backup secret in, on Core-owned wiped memory
**And** `DeriveKeyPair` receives at least 32 bytes of input keying material (REVIEW.md U4), and the `info` of every seal to the backup public key binds a value unique to that seal, such as the backup sequence number, so that a repeated ephemeral seed after a restored snapshot cannot repeat an AEAD key and nonce (U3b)

**Dependencies:**
- Story 4.6 (HPKE suite)
- Story 4.4 (Argon2id derivation on the blocking pool)
